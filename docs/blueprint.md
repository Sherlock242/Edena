# **App Name**: Idea Canvas

## Core Features:

- Canvas Display: Display a blank canvas for users to input their thoughts.
- Text Input: Allow users to add text notes to the canvas.
- Shape Tool: Offer tools to draw basic shapes and lines for visual organization.
- Arrangement and Layout: Provide options to move, resize, and layer elements on the canvas.
- Idea Expansion Tool: Generative AI tool suggests related concepts to expand upon the ideas added to the canvas, if prompted by user. The tool determines whether to use a hierarchical relationship (is-a), compositional relationship (has-a), and property-based relationship (is-like) depending on the subject matter of the ideas being used.
- Save and Load: Enables users to save their current progress to local storage or download canvas states for reuse, including support for various export formats

## Style Guidelines:

- Primary color: A soft blue (#94B49F) for a calming and creative atmosphere.
- Background color: Light, almost white gray (#F0F0F0) to ensure focus on the canvas content.
- Accent color: Muted yellow (#E0C097) to highlight key elements and call-to-action buttons.
- Body and headline font: 'PT Sans' sans-serif, offering a blend of modern style with some personality
- Simple, outlined icons for tools and actions to maintain a clean and intuitive interface.
- A clean, spacious layout that allows users to focus on the canvas, with easily accessible tools.
- Subtle transitions and animations when adding or moving elements to enhance the user experience without being distracting.
